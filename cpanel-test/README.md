# Prueba técnica NutriPediátrica para cPanel

1. Sube el contenido de esta carpeta a la raíz de la aplicación `nutricion` en cPanel.
2. Mantén Node.js 20.20.2, modo **Production** y archivo de inicio `app.js`.
3. Ejecuta **NPM Install**, guarda y reinicia la aplicación.
4. Abre `https://gasfiteriauniversal.cl/nutricion/`.
5. Comprueba también `https://gasfiteriauniversal.cl/nutricion/health`.

No requiere base de datos ni dependencias externas. Si ambas URLs responden, el servidor está listo para el Sprint 0.
